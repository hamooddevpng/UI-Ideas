# Design 37 - Pick Your Path

## Core idea
The first screen asks one direct question: **What do you need today?**

Four large visual choices control the hero:
- Mobile
- Internet
- Business
- Help

There is no automatic carousel. The user chooses the state.

## Dynamic state
Selecting a path changes:
- hero image
- short task message
- contextual action

## Persistent first-screen actions
Always visible:
- Recharge
- Pay Bill
- Self Care
- Get SIM
- Coverage
- Support
- Find Store

## Body
- Visual service menu using photography
- Help and information shortcuts
- News, Careers and Tenders access

## Audience advantage
This is the strongest concept for users with low literacy because the homepage is driven by large icons, pictures and four simple choices rather than reading-heavy navigation.

## Visual direction
Bright white and sky blue, large touch targets, clear selected states, little copy and no dark hero.
