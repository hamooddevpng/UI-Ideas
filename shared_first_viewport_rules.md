# Round 35-38 Shared First-Viewport Rules

## Mandatory first-screen requirements
Every design must treat the first viewport as both a campaign and a service gateway.

The user should immediately see:
- Telikom logo and slogan
- a PNG-first identity line, prototype wording: **Proudly PNG-Owned**
- one short campaign message
- bright PNG-relevant imagery
- a visible icon-based action system
- Recharge / Top Up
- Pay Bill
- Self Care
- Get / Buy SIM
- Coverage
- Support
- Store Locator

## Audience rule
The homepage is for a very broad PNG audience, including users with limited literacy and limited digital confidence.

Therefore:
- prefer recognition over reading
- use large familiar icons
- use short literal labels
- one action per control
- large touch targets
- avoid long paragraphs
- avoid clever copy that must be interpreted
- repeat important tasks where useful
- make support easy to find
- do not hide common tasks in menus

## Visual rule
Dark colours are not preferred for the main customer-facing experience.

Use mainly:
- white
- light neutral backgrounds
- sky blue
- Telikom blue for emphasis and actions
- bright, clear PNG photography

Avoid:
- dark hero sections
- heavy blue overlays on photography
- text over busy images
- low-contrast type
- long blocks of small text
- generic SaaS card walls
- childish Gen Z styling

## Gen Z rule
Gen Z friendliness should come from:
- fast interaction
- strong visual hierarchy
- responsive motion
- tactile controls
- big imagery
- simple self-service
- mobile-first composition

It should not come from slang, memes, stickers everywhere, neon overload or gaming aesthetics.

## Government / enterprise rule
The site must still support Telikom's public, enterprise and government role with clear access to:
- Business services
- Government services
- Remote connectivity
- News and notices
- Careers
- Tenders
- Corporate information

These should be easy to find without making the homepage look old-fashioned.

## Accuracy rule
Do not invent pricing, customer counts, coverage percentages, awards, maps or ownership claims.
Use **Proudly PNG-Owned** only as prototype wording until exact approved ownership language is confirmed.
