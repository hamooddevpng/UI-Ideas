# Design 32 — Swiss Telikom

## Portfolio position
- Gen-Z: **4/10**
- Enterprise / premium: **10/10**
- UX clarity: **10/10**
- PNG identity: **4/10**
- Motion: **2/10**
- Complexity: **4/10**
- Similarity target: **0/10**

## Design thesis
Apply an exceptionally rigorous International/Swiss-style grid to Telikom: typography, numbered sections, asymmetry, alignment and information clarity. This is the “design-system discipline” premium option — no decoration for decoration’s sake.

It should feel more like a world-class transport/infrastructure identity than a conventional telecom ecommerce homepage.

## First viewport
White/pale background. Large logo/slogan. A giant but precise headline occupies a strict grid. A single PNG photo appears as one aligned block, not a background. A numbered service index occupies another grid column.

Example composition:
- 01 Personal
- 02 Home
- 03 Business
- 04 Remote
- 05 Support

Top Up / Self Care are explicit utility buttons.

## Grid system
Use a visible or implied 12-column desktop grid with strong baseline rhythm. Sections deliberately break at different column spans but always align. Mobile becomes a 4-column system.

## Page architecture
1. Grid statement / index.
2. Service directory.
3. Plan comparison.
4. PNG people feature.
5. Business/enterprise directory.
6. Technology/remote chapter.
7. Self Care/support.
8. News/corporate information.
9. Footer.

The section order can be conventional because the *presentation grammar* is radically disciplined and cardless; however, avoid recreating the exact older page sequence.

## Palette
- Telikom Blue `#0875C9`
- Dark Blue `#0E3E5D`
- Pale Grey Blue `#DAE5EB`
- Paper `#F5F7F8`
- Ink `#111F27`
- White `#FFFFFF`
- Rule `#C8D2D8`

Flat colour only. No gradients necessary.

## Typography
Gibson preferred. Use strict type scale, strong numerals and small metadata labels. Avoid trendy display fonts. Large headings should feel architectural.

## Imagery
Use only a few PNG images, all precisely cropped and aligned. Captions sit on baseline grid. No image collages.

## Service presentation
Large text index with rule-separated entries. Hover can reveal supporting image/description, but the text remains useful without hover.

## Plans
True grid/table comparison with consistent numeric alignment. Avoid badges unless necessary. Highlight via blue column/rule.

## Business
This concept should excel for business/government audiences. Use a structured taxonomy and restrained CTA. No unsupported “enterprise-grade” claims unless approved.

## Motion
Almost none. Link underline, focus, image reveal. The restraint is intentional.

## Chatbot
Small conventional launcher fixed bottom-right. Greeting bubble can appear once but should not disrupt grid purity.

## Mobile
Excellent adaptation: preserve typography/rules, stack grid areas in semantic order, use full-width rows. No need for complex alternative interaction.

## Accessibility
High target. Semantic structure, predictable reading order, visible focus, high contrast, meaningful labels, one H1, accessible tables/lists.

## SEO
Excellent. Content-first, crawlable and lightweight. Implement all approved SEO metadata/schema separately from the visual system.

## Performance
Excellent. CSS-first, minimal JavaScript, responsive images. This should be among the fastest concepts.

## CMS
Excellent. Lists/tables/editorial modules accept variable copy lengths more gracefully than tightly designed cards.

## PNG identity strategy
This is intentionally lower on PNG-specific expression. Identity comes from selected photography and content rather than decorative motifs. That makes it a useful portfolio counterpoint to designs 21/27/31.

## Must avoid
- Adding rounded cards or decorative blobs.
- Making it sterile through tiny type and too much empty space.
- Using a generic European city photo or stock image.
- Motion-heavy interactions.
- Blue gradients.

## Success
The homepage should communicate seriousness, order and premium design discipline. A screenshot should look unmistakably different from both existing Telikom and the more expressive concept family.
